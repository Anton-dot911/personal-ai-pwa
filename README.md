# personal-ai-pwa: етап 1

Каркас застосунку: Next.js + PWA, введення ключа Anthropic, стрімінг відповіді Claude і збереження розмов в IndexedDB.

## Запуск локально

```bash
npm install
npm run typecheck
npm run build
npm start
```

Service worker реєструється лише у production-збірці, тому для перевірки PWA використовуйте `npm run build && npm start`.

## Деплой на Vercel

1. Імпортувати репозиторій `personal-ai-pwa` у Vercel. Framework: Next.js, налаштування за замовчуванням.
2. Змінні середовища не потрібні: ключ вводиться в самому застосунку.

## Встановлення на iPhone

1. Відкрити адресу застосунку в Safari.
2. Натиснути «Поділитися» → «На початковий екран».
3. Відкрити застосунок з іконки на головному екрані.

## Перевірка етапу 1 (DoD)

- [ ] 1.1 Застосунок встановлюється з іконки і відкривається без панелі Safari.
- [ ] 1.2 Деплой на Vercel: адреса відкривається з HTTPS.
- [ ] 1.3 Невалідний ключ показує пояснення помилки і не переводить до чату. Валідний ключ переводить до чату.
- [ ] 1.4 Відповідь з'являється поступово. Ключ нігде не відображається в інтерфейсі.
- [ ] 1.5 Після перезавантаження (закрити застосунок і відкрити знову) остання розмова відкривається з усіма повідомленнями.

## Обмеження етапу 1

- Ключ зберігається на пристрої без шифрування. Шифрування паролем додамо пізніше.
- Модель за замовчуванням задана в `lib/config.ts`.
- Контекст розмови це вся її історія. Керування контекстом з'явиться на етапі 2.
- Проєктів ще немає. Вони з'являться на етапі 2.

## Перевірка рушія Excel (етап 3a.1)

Опис зразка витягується з xlsx у JSON, а потім рушій збирає файл назад. Порівняння зі зразком має показати 41 з 41 перевірок.

```bash
python3 scripts/xlsx_extract_spec.py зразок.xlsx lib/xlsx/examples/suppliers.spec.json
npx tsx scripts/xlsx-roundtrip.ts вихід.xlsx
python3 scripts/xlsx_compare.py зразок.xlsx вихід.xlsx
```

Для запуску скриптів потрібен Python з openpyxl і `npm install`.
